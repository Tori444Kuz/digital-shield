# digital-shield
# 🛡️ Цифровой щит

Интерактивный веб-сервис для предварительной оценки коррупционных рисков. Авторская модель оценки на основе системы критериев и баллов, объяснение результатов и рекомендации для жителей Нижегородской области.

## О проекте

«Цифровой щит» — веб-проект, который помогает пользователю структурировать информацию о потенциально коррупционной ситуации, оценить возможные риски и ознакомиться с дальнейшими рекомендациями.

## Возможности

- Интерактивный опрос для оценки ситуации.
- Расчёт предварительного уровня риска на основе системы критериев и баллов.
- Объяснение факторов, повлиявших на результат.
- Рекомендации по дальнейшим действиям.
- Ссылки на информационные и официальные ресурсы.

## Как это работает

Пользователь отвечает на вопросы, после чего программа обрабатывает ответы по заданным правилам, рассчитывает предварительную оценку и показывает результат с пояснениями и рекомендациями.

Модель предназначена для информационного ориентирования и не заменяет юридическую консультацию или официальную проверку.

## Технологии

- HTML5
- CSS3
- JavaScript

## Запуск

Скачайте репозиторий и откройте файл `index.html` в браузере, сохранив структуру файлов проекта.
